# Small Python Tools

I plan to use this repository to share short Python programs for everyday tasks. Examples include organizing file names, summarizing a CSV file, and doing simple unit conversions.

The goal is to keep each script small enough that another student can read it, understand how it works, and adapt it for a different task.

## Current status

The repository currently contains this README and the license. Scripts will be added as they are written.
